## 04. 앱 소개 랜딩 페이지 (v0.17.0)

`https://tether-d1dab.web.app/landing/` 신설. Stitch 디자인(`asset/landing.zip`)을 참고했다.

**Stitch 데스크톱 시안은 채택하지 않았다.** "출시 대기 중", "12,400+ 커플", 앱스토어 다운로드, 이메일 사전예약 등 사실과 다른 내용을 지어냈다. 정확했던 모바일 시안을 기준 삼고 데스크톱은 반응형으로 확장했다.

구성: 히어로 → 기능 카드 6 → **기능 상세 5블록**(스크린샷 자리) → 가입 절차 4단계 + 승인 대기 카드 → 기기별 알림 4탭 → 프라이버시 → CTA

SVIL 표준 준수:
- 자체 완결형 단일 파일, 외부 CDN·스크립트·폰트 0 (아이콘 인라인 SVG)
- 색은 `:root` 토큰만, 고대비 다크 + Tether sage
- 로컬 `LINESeedKR` + 시스템 폴백
- **5개 언어(en/ko/ja/zh/vi), 키 106개 전부 일치**, en 폴백
- 본문 18px, 최소 12px (소장님 지시로 16px 하한 해제)
- 후원 섹션 제외 (성격상 불필요)

스크린샷은 `public/landing/shots/`에 넣으면 자동 표시되고, 없으면 그 자리를 숨긴다. README에 파일명·촬영법·개인정보 주의를 적어뒀다.

부수: workbox `navigateFallbackDenylist`에 `/landing/` 추가(서비스워커가 가로채는 문제), `/landing`에 no-store 캐시 헤더 추가(배포해도 갱신이 안 보이던 문제).

## 05. SVIL 카피라이트 정본 (스킬)

Ghost 블로그 「SVIL 시각지능 연구소」 푸터를 기준으로 공용 표준을 정하고, **단일 정본 구조**로 만들었다.

```
© {연도} SVIL Singularity Visual Intelligence Lab.
```

- 연도는 하드코딩하지 않고 렌더 시점 값(JS 비활성 폴백 유지), 번역하지 않음
- 표준 링크 5개: 문의·블로그·홈페이지(필수) + 유튜브·GitHub(권장)
- 라이선스 문구는 오픈소스만 — Tether에 잘못 붙어 있던 MIT 표기 제거
- **후원은 기본 푸터에서 제외**, 별도 지시가 있을 때만 추가

| 위치 | 역할 |
|---|---|
| `~/.claude/skills/svil-copyright/SKILL.md` | **정본** |
| `svil-frontend-design` | 포인터만 |
| `svil-landing-page` | 포인터만, 기존 푸터 규칙 삭제 |
| 랜딩 템플릿 | 사본 제거, `{{SVIL_FOOTER}}` 자리만 |
| 메모리 | `svil-copyright-standard.md` + MEMORY.md 등록 |

정본 §9에 반영 대상 목록(랜딩 템플릿·Tether 랜딩·Ghost 테마·각 프로젝트 site/)을 두어, 정본 수정 시 따라갈 곳을 명시했다.

## 09. 특이점

**PowerShell로 UTF-8 파일을 조작해 랜딩 페이지 전체를 깨뜨렸다.** `Get-Content`/`Set-Content`가 CP949로 읽어 한중일베 텍스트가 모두 뭉개졌고 그대로 한 번 배포됐다. 복구가 안 돼 파일을 다시 작성했다. **UTF-8 파일에는 PowerShell 텍스트 조작을 쓰지 않는다** — Node나 Python, 또는 편집 도구를 쓴다.
