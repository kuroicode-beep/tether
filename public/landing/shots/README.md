# 랜딩 페이지 스크린샷

이 폴더에 아래 파일명으로 넣으면 랜딩 페이지(`/landing/`)의 기능 설명에 자동으로 나타납니다.
파일이 없으면 그 자리는 통째로 숨겨지므로, 있는 것부터 하나씩 채워도 됩니다.

| 파일명 | 화면 | 위치 |
|---|---|---|
| `chat.png` | 채팅 (사진 캡션이 보이면 좋음) | 채팅 섹션 |
| `relay.png` | 릴레이소설 (상단 차례 띠 + 턴 카드) | 릴레이소설 섹션 |
| `home.png` | 홈 (오늘의 상태) | 오늘의 상태 섹션 |
| `diary.png` | 교환일기 | 교환일기 섹션 |
| `listen.png` | 같이듣기 | 같이듣기 섹션 |

## 찍는 방법

아이폰이면 홈 화면 앱으로 실행한 뒤 전원+볼륨업, PC면 브라우저 창을 모바일 폭으로 줄여 캡처합니다.
가로 폭 750~1200px 정도면 충분합니다. PNG 권장.

## 주의 — 개인정보

**공개 페이지에 올라갑니다.** 실제 대화 내용, 이름, 사진, 이메일이 그대로 노출되니
캡처 전에 다음 중 하나로 정리해주세요.

- 보여줘도 괜찮은 내용만 남기고 캡처
- 캡처 후 이름·본문을 가리거나 흐리게 처리
- 릴레이소설처럼 창작물 위주 화면을 고르기

프로필 사진과 닉네임도 함께 찍히니 확인해주세요.
